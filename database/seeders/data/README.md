# Data wilayah Kepulauan Riau

Koordinat dan kode wilayah pada `kepri_regions.json` disusun dari `koordinat_kepri_fix.xlsx` yang disediakan untuk proyek ini. Workbook mencatat sumber batas wilayah `github.com/cahyadsn/wilayah_boundaries` (MIT); koordinat yang dipakai adalah centroid tiap wilayah. Centroid pulau kecil dapat berada di laut dan nilai Open-Meteo adalah estimasi titik model, bukan observasi stasiun lokal.
